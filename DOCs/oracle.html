Propósito de la guía

Esta guía tiene como objetivo acompañar al alumno, paso a paso, en la instalación y uso básico de Oracle Database 21c Express Edition en Windows, utilizando PowerShell como consola principal de trabajo.

Al finalizar, el alumno será capaz de:

  • Instalar Oracle Database 21c XE en Windows.
  • Verificar que los servicios de Oracle estén activos.
  • Conectarse a Oracle desde PowerShell mediante SQL*Plus.
  • Comprender la diferencia entre base de datos, usuario y esquema en Oracle.
  • Crear usuarios académicos con permisos controlados.
  • Crear tablas relacionales con claves primarias y foráneas.
  • Insertar, consultar, actualizar y eliminar datos.
  • Configurar DBeaver como cliente gráfico para conectarse a Oracle XE.
  • Ejecutar scripts .sql desde PowerShell para automatizar prácticas.
El enfoque es académico. Las contraseñas usadas son ejemplos para laboratorio y no deben utilizarse en ambientes reales de producción.
2

Conceptos mínimos antes de instalar

Antes de ejecutar comandos, es importante entender cómo organiza Oracle sus componentes. Muchos errores de alumnos ocurren porque intentan trabajar Oracle como si fuera MySQL, SQL Server o Access.

ConceptoExplicación sencillaEjemplo en Oracle XE
Base de datosConjunto de archivos, memoria y procesos donde se guardan y administran los datos.XE
InstanciaProcesos y memoria que permiten abrir y operar la base de datos.Instancia XE
CDBContainer Database. Es el contenedor principal de Oracle multitenant.CDB$ROOT, servicio XE
PDBPluggable Database. Es la base de trabajo donde se crean usuarios de práctica.XEPDB1
ServicioNombre usado para conectarse a una base o PDB por red.//localhost:1521/XEPDB1
ListenerServicio que escucha conexiones externas o locales por TCP/IP.Puerto 1521
UsuarioCuenta que permite iniciar sesión en Oracle.alumno_prg2
EsquemaConjunto de objetos que pertenecen a un usuario: tablas, vistas, secuencias, procedimientos.Tablas creadas por alumno_prg2
TablespaceEspacio lógico donde Oracle almacena los objetos de los usuarios.USERS
En Oracle, cuando se crea un usuario, también se crea su esquema. Por eso, para una práctica universitaria normalmente se crea un usuario por alumno o por grupo. Ese usuario será dueño de sus tablas.
3

Requisitos previos

Antes de instalar, revise los siguientes puntos:

  • Usar Windows de 64 bits en una edición compatible con Oracle XE.
  • Ingresar con una cuenta que sea miembro directo del grupo Administradores de Windows.
  • No tener instalada otra versión de Oracle XE con el mismo SID XE.
  • Eliminar o desactivar temporalmente variables de entorno antiguas ORACLE_HOME o TNS_ADMIN si existen.
  • Tener espacio suficiente en disco. El instalador ocupa varios GB y la base puede crecer durante las prácticas.
  • Tener permisos para iniciar, detener y consultar servicios de Windows.

Comandos previos de diagnóstico en PowerShell

PowerShell — Diagnóstico previo a la instalación
# Verificar la versión y arquitectura de Windows
Get-ComputerInfo | Select-Object WindowsProductName, WindowsVersion, OsArchitecture

# Verificar si existen variables de entorno Oracle antiguas
[Environment]::GetEnvironmentVariable("ORACLE_HOME", "Machine")
[Environment]::GetEnvironmentVariable("TNS_ADMIN",  "Machine")

# Verificar si ya existen servicios Oracle instalados
Get-Service *Oracle* | Select-Object Name, Status, StartType
Si aparecen servicios Oracle antiguos y el laboratorio requiere una instalación limpia, no elimine carpetas manualmente sin indicación del docente. Primero se debe desinstalar correctamente desde Windows.
4

Descarga e instalación de Oracle 21c XE

4.1 Descargar Oracle Database 21c Express Edition

Ingrese al sitio oficial de Oracle y descargue la versión para Microsoft Windows de 64 bits. El archivo suele llamarse OracleXE213_Win64.zip.

Página oficial de descarga: Oracle Database XE Downloads — busque en oracle.com/database/technologies/xe-downloads.html

4.2 Extraer el archivo ZIP

  1. Cree una carpeta temporal, por ejemplo C:\oracle_instalador.
  2. Copie el archivo ZIP a esa carpeta.
  3. Haga clic derecho sobre el ZIP y seleccione Extraer todo.
  4. Verifique que dentro de la carpeta extraída exista el archivo setup.exe.
PowerShell — Crear carpeta y abrirla
# Crear carpeta temporal para el instalador
New-Item -ItemType Directory -Path C:\oracle_instalador -Force

# Abrir la carpeta desde PowerShell
explorer C:\oracle_instalador

4.3 Ejecutar el instalador

  1. Ubique el archivo setup.exe dentro de la carpeta extraída.
  2. Ejecute setup.exe. Si Windows solicita permisos, acepte la elevación.
  3. En la pantalla de bienvenida, seleccione Next.
  4. Acepte el acuerdo de licencia si corresponde al uso académico indicado.
  5. Use una carpeta de instalación sin espacios en la ruta. Se recomienda aceptar la ruta propuesta.
  6. Defina la contraseña para las cuentas administrativas SYS, SYSTEM y PDBADMIN.
  7. Anote la contraseña en un lugar seguro. Sin ella, no podrá administrar la base.
  8. Finalice la instalación y registre las cadenas de conexión mostradas al final.
Use una contraseña de laboratorio con mayúscula, minúscula, número y símbolo. Ejemplo didáctico: AdminWeb2026#. Cada alumno debe reemplazarla por una propia.
5

Verificación inicial desde PowerShell

Después de instalar, no se debe comenzar a crear tablas inmediatamente. Primero se verifica que Oracle esté activo.

5.1 Abrir PowerShell

Presione Inicio, escriba PowerShell y abra Windows PowerShell. Para administrar servicios, conviene ejecutarlo como administrador.

5.2 Verificar servicios de Oracle

PowerShell — Verificar estado de servicios
# Listar todos los servicios Oracle instalados en Windows
Get-Service *Oracle* | Select-Object Name, Status, StartType

# Verificar el servicio principal de la base XE
Get-Service OracleServiceXE

# Buscar el servicio listener (el nombre puede variar según el equipo)
Get-Service *TNSListener*

Resultado esperado:

  • OracleServiceXE debe estar en estado Running.
  • El servicio listener debe estar en estado Running.
  • Si están detenidos, se deben iniciar antes de conectarse.

5.3 Iniciar y detener servicios

PowerShell — Iniciar / Detener Oracle XE
# Iniciar el servicio principal de Oracle XE
Start-Service OracleServiceXE

# Iniciar el listener (busque primero el nombre real con Get-Service *TNSListener*)
Start-Service OracleOraDB21Home1TNSListener

# Detener el servicio principal (solo si el docente lo solicita)
Stop-Service OracleServiceXE
No todos los equipos tendrán exactamente el mismo nombre de listener. Por eso primero se usa Get-Service *TNSListener* y luego se copia el nombre real del servicio.
6

Conexión a Oracle desde PowerShell con SQL*Plus

SQL*Plus es una herramienta de línea de comandos incluida con Oracle. Permite conectarse a la base de datos y ejecutar sentencias SQL.

6.1 Ubicar SQL*Plus

PowerShell — Buscar sqlplus.exe
# Buscar sqlplus.exe dentro de C:\app
Get-ChildItem "C:\app" -Recurse -Filter sqlplus.exe -ErrorAction SilentlyContinue |
    Select-Object -First 1 -ExpandProperty FullName

Una ruta típica puede ser:

C:\app\<usuario_windows>\product\21.0.0\dbhomeXE\bin\sqlplus.exe

6.2 Entrar a la carpeta bin de Oracle

PowerShell — Navegar a la carpeta bin
# Reemplace <usuario_windows> por el nombre de su usuario real de Windows
cd C:\app\<usuario_windows>\product\21.0.0\dbhomeXE\bin

# Probar que SQL*Plus responde
.\sqlplus -V
Si sqlplus no se reconoce, puede ser solo un problema de PATH. Entre a la carpeta bin y ejecute .\sqlplus con el punto y barra al inicio.

6.3 Verificar el listener

PowerShell — Estado del listener
# Desde la carpeta bin de Oracle
.\lsnrctl status

En la salida deben aparecer servicios como XE y XEPDB1. El servicio XEPDB1 es el que se usará para crear usuarios y tablas de laboratorio.

6.4 Conectarse como administrador

PowerShell — Conexiones SQL*Plus
-- Forma recomendada: conectarse a XEPDB1 con SYSTEM para crear usuarios de laboratorio
.\sqlplus system/SuPassword@//localhost:1521/XEPDB1

-- También puede conectarse como SYSDBA al contenedor principal (usar con cuidado)
.\sqlplus sys/SuPassword@//localhost:1521/XE as sysdba
Para crear usuarios normales de clase, conéctese a XEPDB1, no al contenedor raíz XE/CDB$ROOT. Si se conecta al lugar incorrecto, aparecerá el error ORA-65096.

6.5 Comandos básicos dentro de SQL*Plus

SQL*Plus — Comandos de orientación
-- Ver con qué usuario está conectado
SHOW USER;

-- Ver en qué contenedor está conectado
SHOW CON_NAME;

-- Ver PDBs disponibles (solo conectado como SYSDBA al CDB)
SHOW PDBS;

-- Salir de SQL*Plus
EXIT;
7

Creación de usuarios y esquemas

En Oracle, un usuario puede iniciar sesión y también puede ser propietario de objetos. El esquema es el conjunto de objetos que pertenecen a ese usuario. Por ejemplo, si el usuario alumno_prg2 crea una tabla llamada alumnos, esa tabla pertenece al esquema alumno_prg2.

7.1 Conectarse a XEPDB1 como SYSTEM

PowerShell — Conexión administrativa a XEPDB1
cd C:\app\<usuario_windows>\product\21.0.0\dbhomeXE\bin
.\sqlplus system/SuPassword@//localhost:1521/XEPDB1

7.2 Crear un usuario académico

SQL — CREATE USER línea por línea
CREATE USER alumno_prg2               -- Nombre de la nueva cuenta
    IDENTIFIED BY Alumno2026#           -- Contraseña del usuario
    DEFAULT TABLESPACE users            -- Sus objetos se guardan en USERS
    TEMPORARY TABLESPACE temp           -- Espacio para ordenamientos internos
    QUOTA 100M ON users;                -- Permite usar hasta 100 MB

7.3 Otorgar permisos mínimos de laboratorio

SQL — GRANT de privilegios académicos
GRANT CREATE SESSION   TO alumno_prg2;  -- Permite iniciar sesión
GRANT CREATE TABLE     TO alumno_prg2;  -- Permite crear tablas
GRANT CREATE VIEW      TO alumno_prg2;  -- Permite crear vistas
GRANT CREATE SEQUENCE  TO alumno_prg2;  -- Permite crear secuencias
GRANT CREATE PROCEDURE TO alumno_prg2;  -- Permite crear procedimientos
No otorgue DBA a usuarios de alumnos. DBA es un permiso administrativo amplio y no corresponde a prácticas iniciales. Para clase basta con CREATE SESSION, CREATE TABLE y otros permisos específicos.

7.4 Probar conexión con el nuevo usuario

PowerShell + SQL*Plus — Verificar conexión del alumno
EXIT;   -- Salir de la sesión SYSTEM

# Conectarse con el usuario recién creado
.\sqlplus alumno_prg2/Alumno2026#@//localhost:1521/XEPDB1

-- Dentro de SQL*Plus, verificar identidad y contenedor
SHOW USER;
SHOW CON_NAME;
USER is "ALUMNO_PRG2"
CON_NAME
------------------------------
XEPDB1
8

Creación de tablas del caso académico

Para practicar diseño relacional, se usará un caso sencillo: gestión académica básica con carreras, alumnos, materias, inscripciones y evaluaciones.

TablaQué representaClave principal
carrerasCarreras habilitadas en la institución.id_carrera
alumnosDatos básicos de alumnos.id_alumno
materiasMaterias disponibles.id_materia
inscripcionesRelación entre alumnos y materias.id_inscripcion
evaluacionesPuntajes obtenidos por inscripción.id_evaluacion
Conectarse como alumno_prg2 a XEPDB1 antes de ejecutar los CREATE TABLE.

8.1 Tabla carreras

SQL — CREATE TABLE carreras
CREATE TABLE carreras (
    id_carrera NUMBER GENERATED BY DEFAULT AS IDENTITY,
    nombre     VARCHAR2(100) NOT NULL,
    estado     CHAR(1) DEFAULT 'A' NOT NULL,
    CONSTRAINT pk_carreras        PRIMARY KEY (id_carrera),
    CONSTRAINT ck_carreras_estado CHECK (estado IN ('A','I'))  -- A=Activa I=Inactiva
);

8.2 Tabla alumnos

SQL — CREATE TABLE alumnos
CREATE TABLE alumnos (
    id_alumno      NUMBER GENERATED BY DEFAULT AS IDENTITY,
    cedula         VARCHAR2(20)  NOT NULL,
    nombre         VARCHAR2(80)  NOT NULL,
    apellido       VARCHAR2(80)  NOT NULL,
    email          VARCHAR2(120),
    fecha_registro DATE DEFAULT SYSDATE NOT NULL,
    id_carrera     NUMBER NOT NULL,
    CONSTRAINT pk_alumnos         PRIMARY KEY (id_alumno),
    CONSTRAINT uk_alumnos_cedula  UNIQUE (cedula),
    CONSTRAINT fk_alumnos_carreras FOREIGN KEY (id_carrera)
        REFERENCES carreras(id_carrera)
);

8.3 Tabla materias

SQL — CREATE TABLE materias
CREATE TABLE materias (
    id_materia NUMBER GENERATED BY DEFAULT AS IDENTITY,
    nombre     VARCHAR2(100) NOT NULL,
    semestre   NUMBER(2) NOT NULL,
    creditos   NUMBER(2) DEFAULT 4 NOT NULL,
    CONSTRAINT pk_materias          PRIMARY KEY (id_materia),
    CONSTRAINT ck_materias_semestre CHECK (semestre BETWEEN 1 AND 10),
    CONSTRAINT ck_materias_creditos CHECK (creditos BETWEEN 1 AND 10)
);

8.4 Tabla inscripciones

SQL — CREATE TABLE inscripciones
CREATE TABLE inscripciones (
    id_inscripcion    NUMBER GENERATED BY DEFAULT AS IDENTITY,
    id_alumno         NUMBER NOT NULL,
    id_materia        NUMBER NOT NULL,
    fecha_inscripcion DATE DEFAULT SYSDATE NOT NULL,
    estado            VARCHAR2(20) DEFAULT 'INSCRIPTO' NOT NULL,
    CONSTRAINT pk_inscripciones         PRIMARY KEY (id_inscripcion),
    CONSTRAINT fk_ins_alumno             FOREIGN KEY (id_alumno)
        REFERENCES alumnos(id_alumno),
    CONSTRAINT fk_ins_materia            FOREIGN KEY (id_materia)
        REFERENCES materias(id_materia),
    CONSTRAINT uk_ins_alumno_materia     UNIQUE (id_alumno, id_materia),
    CONSTRAINT ck_ins_estado             CHECK (estado IN
        ('INSCRIPTO','APROBADO','REPROBADO','RETIRADO'))
);

8.5 Tabla evaluaciones

SQL — CREATE TABLE evaluaciones
CREATE TABLE evaluaciones (
    id_evaluacion    NUMBER GENERATED BY DEFAULT AS IDENTITY,
    id_inscripcion   NUMBER NOT NULL,
    tipo             VARCHAR2(30) NOT NULL,
    puntaje          NUMBER(5,2) NOT NULL,
    fecha_evaluacion DATE DEFAULT SYSDATE NOT NULL,
    CONSTRAINT pk_evaluaciones      PRIMARY KEY (id_evaluacion),
    CONSTRAINT fk_eval_inscripcion  FOREIGN KEY (id_inscripcion)
        REFERENCES inscripciones(id_inscripcion),
    CONSTRAINT ck_eval_tipo         CHECK (tipo IN
        ('PARCIAL','FINAL','RECUPERATORIO','TRABAJO')),
    CONSTRAINT ck_eval_puntaje      CHECK (puntaje BETWEEN 0 AND 100)
);

8.6 Verificar tablas creadas

SQL — Consultar el catálogo del esquema
SELECT table_name
FROM   user_tables
ORDER BY table_name;

DESCRIBE alumnos;
DESCRIBE inscripciones;

Inserción y consulta de datos

9.1 Insertar datos iniciales

SQL — INSERT de datos de prueba
INSERT INTO carreras (nombre) VALUES ('Ingeniería en Informática');
INSERT INTO carreras (nombre) VALUES ('Ingeniería Comercial');

INSERT INTO materias (nombre, semestre, creditos) VALUES ('Programación 2', 3, 5);
INSERT INTO materias (nombre, semestre, creditos) VALUES ('Base de Datos 1', 4, 5);

INSERT INTO alumnos (cedula, nombre, apellido, email, id_carrera)
VALUES ('1234567', 'Ana', 'Gómez', 'ana.gomez@correo.com', 1);

INSERT INTO alumnos (cedula, nombre, apellido, email, id_carrera)
VALUES ('2345678', 'Carlos', 'Pérez', 'carlos.perez@correo.com', 1);

INSERT INTO inscripciones (id_alumno, id_materia) VALUES (1, 1);
INSERT INTO inscripciones (id_alumno, id_materia) VALUES (2, 1);

INSERT INTO evaluaciones (id_inscripcion, tipo, puntaje) VALUES (1, 'PARCIAL', 85);
INSERT INTO evaluaciones (id_inscripcion, tipo, puntaje) VALUES (2, 'PARCIAL', 72);

COMMIT;  -- Confirmar todos los cambios

9.2 Consultas básicas

SQL — SELECT simples por tabla
SELECT * FROM carreras;
SELECT * FROM alumnos;
SELECT * FROM materias;
SELECT * FROM inscripciones;
SELECT * FROM evaluaciones;

9.3 Consulta con JOIN

SQL — Consulta completa con múltiples JOINs
SELECT
    a.nombre || ' ' || a.apellido  AS alumno,
    c.nombre                        AS carrera,
    m.nombre                        AS materia,
    i.estado                        AS estado_inscripcion,
    e.tipo                          AS evaluacion,
    e.puntaje
FROM       alumnos a
JOIN       carreras c      ON c.id_carrera    = a.id_carrera
JOIN       inscripciones i ON i.id_alumno     = a.id_alumno
JOIN       materias m      ON m.id_materia    = i.id_materia
LEFT JOIN  evaluaciones e  ON e.id_inscripcion = i.id_inscripcion
ORDER BY   a.apellido, a.nombre;

9.4 Actualizar y eliminar datos

SQL — UPDATE y DELETE controlados
-- Actualizar un puntaje existente
UPDATE evaluaciones
SET    puntaje = 90
WHERE  id_evaluacion = 1;

COMMIT;

-- Eliminar una evaluación específica
DELETE FROM evaluaciones
WHERE  id_evaluacion = 2;

COMMIT;
No elimine registros padres si existen registros hijos relacionados. Por ejemplo, no podrá eliminar un alumno que ya tiene inscripciones sin antes eliminar o modificar esas inscripciones.

Administración básica de usuarios

Estos comandos deben ejecutarse conectado como SYSTEM en XEPDB1.

SQL — Administración de cuentas de usuario
-- Cambiar contraseña
ALTER USER alumno_prg2 IDENTIFIED BY NuevaClave2026#;

-- Bloquear cuenta
ALTER USER alumno_prg2 ACCOUNT LOCK;

-- Desbloquear cuenta
ALTER USER alumno_prg2 ACCOUNT UNLOCK;

-- Aumentar cuota de almacenamiento
ALTER USER alumno_prg2 QUOTA 200M ON users;

-- Ver usuarios creados en la PDB
SELECT username, account_status, default_tablespace
FROM   dba_users
WHERE  username LIKE 'ALUMNO%'
ORDER BY username;
Para eliminar un usuario y todos sus objetos se usa DROP USER usuario CASCADE. Este comando borra tablas, datos y objetos del esquema. Debe usarse solo con autorización del docente.

Ejemplo: DROP USER alumno_prg2 CASCADE;

Ejecución de scripts .sql desde PowerShell

En lugar de escribir todo manualmente dentro de SQL*Plus, se pueden crear archivos .sql y ejecutarlos desde PowerShell. Esto es más ordenado y reduce errores.

11.1 Crear carpeta de laboratorio

PowerShell — Preparar carpeta de trabajo
New-Item -ItemType Directory -Path C:\oracle_lab -Force
notepad C:\oracle_lab\01_crear_usuario.sql

11.2 Contenido del script 01_crear_usuario.sql

SQL — 01_crear_usuario.sql
CREATE USER grupo01
    IDENTIFIED BY Grupo012026#
    DEFAULT TABLESPACE users
    TEMPORARY TABLESPACE temp
    QUOTA 100M ON users;

GRANT CREATE SESSION   TO grupo01;
GRANT CREATE TABLE     TO grupo01;
GRANT CREATE VIEW      TO grupo01;
GRANT CREATE SEQUENCE  TO grupo01;

EXIT;

11.3 Ejecutar el script desde PowerShell

PowerShell — Llamar SQL*Plus con un archivo .sql
cd C:\app\<usuario_windows>\product\21.0.0\dbhomeXE\bin

# El símbolo @ le indica a SQL*Plus que ejecute un archivo
.\sqlplus system/SuPassword@//localhost:1521/XEPDB1 @C:\oracle_lab\01_crear_usuario.sql

11.4 Guardar evidencia con SPOOL

SQL — Capturar salida en un archivo de texto
-- SPOOL inicia la grabación de la sesión en un archivo .txt
SPOOL C:\oracle_lab\evidencia_alumno_prg2.txt

SHOW USER;
SHOW CON_NAME;

SELECT table_name FROM user_tables ORDER BY table_name;
SELECT COUNT(*) AS cantidad_alumnos FROM alumnos;

SPOOL OFF;  -- Detener la grabación
EXIT;
SPOOL crea un archivo de texto con toda la salida de SQL*Plus. Es útil para entregar evidencia de la práctica sin depender únicamente de capturas de pantalla.

Práctica integradora final

El alumno debe realizar la siguiente práctica en su equipo o laboratorio:

  1. Instalar o verificar Oracle Database 21c XE.
  2. Comprobar servicios de Oracle desde PowerShell.
  3. Conectarse a XEPDB1 con SQL*Plus.
  4. Crear un usuario llamado practica_apellido, reemplazando apellido por el suyo.
  5. Otorgar permisos mínimos: CREATE SESSION, CREATE TABLE, CREATE VIEW y CREATE SEQUENCE.
  6. Conectarse con el usuario creado.
  7. Crear las tablas carreras, alumnos, materias, inscripciones y evaluaciones.
  8. Insertar al menos 3 carreras, 5 alumnos, 4 materias, 5 inscripciones y 5 evaluaciones.
  9. Ejecutar una consulta JOIN que muestre alumno, carrera, materia y puntaje.
  10. Guardar evidencia con SPOOL y entregar el archivo resultante.

CREATE TABLE carreras (
    id_carrera NUMBER GENERATED BY DEFAULT AS IDENTITY,
    nombre     VARCHAR2(100) NOT NULL,
    estado     CHAR(1) DEFAULT 'A' NOT NULL,
    CONSTRAINT pk_carreras        PRIMARY KEY (id_carrera),
    CONSTRAINT ck_carreras_estado CHECK (estado IN ('A','I'))
);

CREATE TABLE alumnos (
    id_alumno      NUMBER GENERATED BY DEFAULT AS IDENTITY,
    cedula         VARCHAR2(20)  NOT NULL,
    nombre         VARCHAR2(80)  NOT NULL,
    apellido       VARCHAR2(80)  NOT NULL,
    email          VARCHAR2(120),
    fecha_registro DATE DEFAULT SYSDATE NOT NULL,
    id_carrera     NUMBER NOT NULL,
    CONSTRAINT pk_alumnos          PRIMARY KEY (id_alumno),
    CONSTRAINT uk_alumnos_cedula   UNIQUE (cedula),
    CONSTRAINT fk_alumnos_carreras FOREIGN KEY (id_carrera)
        REFERENCES carreras(id_carrera)
);

CREATE TABLE materias (
    id_materia NUMBER GENERATED BY DEFAULT AS IDENTITY,
    nombre     VARCHAR2(100) NOT NULL,
    semestre   NUMBER(2) NOT NULL,
    creditos   NUMBER(2) DEFAULT 4 NOT NULL,
    CONSTRAINT pk_materias          PRIMARY KEY (id_materia),
    CONSTRAINT ck_materias_semestre CHECK (semestre BETWEEN 1 AND 10),
    CONSTRAINT ck_materias_creditos CHECK (creditos BETWEEN 1 AND 10)
);

CREATE TABLE inscripciones (
    id_inscripcion    NUMBER GENERATED BY DEFAULT AS IDENTITY,
    id_alumno         NUMBER NOT NULL,
    id_materia        NUMBER NOT NULL,
    fecha_inscripcion DATE DEFAULT SYSDATE NOT NULL,
    estado            VARCHAR2(20) DEFAULT 'INSCRIPTO' NOT NULL,
    CONSTRAINT pk_inscripciones     PRIMARY KEY (id_inscripcion),
    CONSTRAINT fk_ins_alumno        FOREIGN KEY (id_alumno)
        REFERENCES alumnos(id_alumno),
    CONSTRAINT fk_ins_materia       FOREIGN KEY (id_materia)
        REFERENCES materias(id_materia),
    CONSTRAINT uk_ins_alumno_materia UNIQUE (id_alumno, id_materia),
    CONSTRAINT ck_ins_estado        CHECK (estado IN
        ('INSCRIPTO','APROBADO','REPROBADO','RETIRADO'))
);

CREATE TABLE evaluaciones (
    id_evaluacion    NUMBER GENERATED BY DEFAULT AS IDENTITY,
    id_inscripcion   NUMBER NOT NULL,
    tipo             VARCHAR2(30) NOT NULL,
    puntaje          NUMBER(5,2) NOT NULL,
    fecha_evaluacion DATE DEFAULT SYSDATE NOT NULL,
    CONSTRAINT pk_evaluaciones     PRIMARY KEY (id_evaluacion),
    CONSTRAINT fk_eval_inscripcion FOREIGN KEY (id_inscripcion)
        REFERENCES inscripciones(id_inscripcion),
    CONSTRAINT ck_eval_tipo        CHECK (tipo IN
        ('PARCIAL','FINAL','RECUPERATORIO','TRABAJO')),
    CONSTRAINT ck_eval_puntaje     CHECK (puntaje BETWEEN 0 AND 100)
);

EXIT;

    a.nombre || ' ' || a.apellido AS alumno,

B

Anexo B — Instalación y configuración de DBeaver para Oracle 21c XE

Este complemento muestra cómo instalar DBeaver en Windows y configurarlo para trabajar con Oracle Database 21c Express Edition. La finalidad es que el alumno pueda ejecutar consultas SQL, revisar sus tablas y validar datos desde una interfaz gráfica.

DBeaver no reemplaza a Oracle. Oracle es el motor de base de datos; DBeaver es un cliente que se conecta a Oracle mediante JDBC para facilitar la administración y ejecución de SQL.

B.1 Objetivos del complemento

  • Instalar DBeaver Community en Windows.
  • Crear una conexión gráfica hacia Oracle XE usando el servicio XEPDB1.
  • Conectarse con el usuario / esquema creado en la guía principal.
  • Ejecutar scripts SQL desde el editor de DBeaver.
  • Crear tablas, insertar datos, consultar registros y verificar errores.
  • Diferenciar entre conexión administrativa del docente y conexión académica del alumno.

B.2 Requisitos previos antes de abrir DBeaver

Antes de configurar DBeaver, Oracle XE debe estar funcionando. Si Oracle no responde, DBeaver tampoco podrá conectarse.

PowerShell — Diagnóstico antes de abrir DBeaver
# Verificar servicios de Oracle
Get-Service *Oracle* | Select-Object Name, Status, StartType

# Verificar si el puerto 1521 responde en la máquina local
Test-NetConnection localhost -Port 1521

# Probar conexión directa con SQL*Plus antes de usar DBeaver
sqlplus alumno01/Alumno2026#@//localhost:1521/XEPDB1
Si Test-NetConnection indica TcpTestSucceeded: False, revise que el listener esté iniciado. Si SQL*Plus no conecta, corrija primero Oracle antes de abrir DBeaver.

B.3 Instalar DBeaver Community

  1. Ingresar al sitio oficial de DBeaver y descargar la edición Community para Windows.
  2. Seleccionar el instalador estándar para Windows (no portable, salvo indicación del docente).
  3. Ejecutar el archivo descargado. Si Windows solicita permisos de administrador, aceptarlos.
  4. Avanzar con Next en el asistente de instalación y aceptar la licencia.
  5. Mantener las opciones predeterminadas de instalación.
  6. Finalizar la instalación y abrir DBeaver desde el menú Inicio.
Las versiones actuales de DBeaver para Windows incluyen OpenJDK integrado, por lo que normalmente el alumno no necesita instalar Java manualmente.

B.4 Crear la conexión de alumno hacia Oracle XE

  1. Abrir DBeaver → menú Database > New Database Connection (Ctrl+Shift+N).
  2. En la lista de motores, buscar y seleccionar Oracle. Si DBeaver solicita descargar el driver JDBC, aceptar.
  3. Completar los datos de conexión de la tabla siguiente.
  4. Presionar Test Connection. Si muestra "Connected", presionar Finish.

B.7 Diferencia entre trabajar con el usuario propio y cambiar de esquema

La forma correcta para estudiantes es que cada uno se conecte con su propio usuario. En Oracle, el usuario y el esquema tienen una relación directa.
