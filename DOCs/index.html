Programación 2 — Proyecto WEB

Guía de recursos didácticos: Oracle XE 21c · Node.js · CRUD · PowerShell

PR2 · Bases de Datos Prof. Richard Steven 2025

Esta página centraliza todos los recursos del proyecto WEB de Programación 2. Los documentos están ordenados de forma progresiva en 7 pasos: cada fase consolida los conocimientos de la anterior. Seguir el orden indicado garantiza una comprensión completa del proceso, desde la base de datos hasta la aplicación web funcional.

Las guías de documentación (pasos 0 al 6) explican conceptos y muestran código paso a paso. Las páginas de aplicación (paso 7) son el resultado final que el alumno debe construir y demostrar funcionando.
