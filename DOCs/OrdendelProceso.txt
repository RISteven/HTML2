Orden sugerido para la clase

BLOQUE 0 — Infraestructura (explicar, no codificar en clase)
Mostrar ya hecho o dictarlo como tarea previa:

1- SQL → Crear tabla + insertar registro de prueba
2- db.js → Configuración de conexión Oracle (2 minutos, muy simple)
3- server.js → Punto de entrada del servidor (explicar estructura)
4- styles.css → Copiar/pegar, no es el foco pedagógico

BLOQUE 1 — Login (primer resultado visible)
Objetivo: el estudiante ve la app funcionar por primera vez

login.html → Formulario + fetch() al servidor
routes/login.js → Ruta POST /api/login + consulta SQL
¿Por qué primero el HTML? El estudiante entiende QUÉ necesita el frontend antes de escribir el backend.

BLOQUE 2 — Menú
menu.html → HTML puro, sin lógica de servidor (refuerza el flujo login → menú)

BLOQUE 3 — Consultar / Listar (la operación más simple)
Introduce GET, la operación de solo lectura

listar.html → fetch GET + construir tabla con JavaScript
routes/usuarios.js → solo el GET /api/usuarios

BLOQUE 4 — Crear / Alta

crear.html → Formulario + fetch POST
routes/usuarios.js → agregar POST /api/usuarios

BLOQUE 5 — Modificar
actualizar.html → Formulario + fetch PUT
routes/usuarios.js → agregar PUT /api/usuarios/:nombre

BLOQUE 6 — Eliminar
eliminar.html → Formulario + fetch DELETE
routes/usuarios.js → agregar DELETE /api/usuarios/:nombre
