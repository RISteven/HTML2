N
¿Qué es Node.js?

Entorno que permite ejecutar JavaScript fuera del navegador, en el servidor. Cumple el rol de SERVIDOR.

✔ Usa JavaScript, el mismo lenguaje del navegador.
✔ Liviano y rápido para muchas peticiones.
✔ Ecosistema enorme de librerías (npm).
✔ Express crea un servidor con pocas líneas.
O
¿Qué es Oracle XE?

Versión gratuita de Oracle Database. Motor relacional que cumple el rol de ALMACÉN DE DATOS.

XEPDB1 es el nombre de la base de datos (PDB = Pluggable DataBase) que viene creada por defecto en Oracle XE 21c.

Instalación

1
Instalación de Oracle XE 21c
1
Descargar Oracle XE 21c
Ir a oracle.com/database/technologies/xe-downloads.html → descargar Oracle Database 21c Express Edition for Windows x64 (≈1.5 GB, archivo OracleXE213_Win64.zip).
2
Instalar
Descomprimir el ZIP → ejecutar setup.exe como Administrador → seguir el asistente → anotar la contraseña de SYS. Puede demorar 10-15 min.
3
Verificar que Oracle está corriendo
Inicio → Servicios → verificar que OracleServiceXE está en estado "En ejecución". Si no, clic derecho → Iniciar.
4
Conectar con SQL Developer
Usuario: system · Contraseña: la de la instalación · Host: localhost · Puerto: 1521 · SID: XE o Service Name: XEPDB1
2
Instalación de Node.js
1
Descargar
Ir a nodejs.org → descargar la versión LTS (Long Term Support). El instalador: node-v##.##.#-x64.msi.
2
Instalar
Ejecutar el .msi con todos los valores predeterminados. Asegurarse de que "Add to PATH" esté marcado (viene por defecto).
3
Verificar en PowerShell o CMD
PowerShell 
node --version    # debe mostrar: v20.11.0 (o similar)
npm  --version    # debe mostrar: 10.2.4  (o similar)

Configuración

Configuración de Conexión a Oracle — db.js

Crear el archivo db.js dentro de la carpeta js\:

JavaScript — db.js 
const oracledb = require('oracledb');

const configuracion = {
  user:          "prg2",             // Usuario de Oracle
  password:      "curso2026",        // Contraseña del usuario
  connectString: "localhost/XEPDB1"  // Host / Base de datos
};

module.exports = configuracion;
connectString:
· localhost → la base de datos está en la misma computadora.
· XEPDB1 → nombre de la PDB de Oracle XE 21c.

Código del servidor

6
Servidor Express con Ruta de Login — server.js

Crear el archivo server.js dentro de la carpeta js\:

JavaScript — server.js 
const express    = require('express');
const oracledb   = require('oracledb');
const bodyParser = require('body-parser');
const config     = require('./db');

const app = express();
app.use(bodyParser.urlencoded({ extended: true }));
app.use(bodyParser.json());
app.use(express.static('../public'));  // sirve los archivos HTML

// Ruta de login
app.post('/login', async (req, res) => {
  const { usuario, clave } = req.body;

  try {
    const connection = await oracledb.getConnection(config);

    const result = await connection.execute(
      `SELECT * FROM usuarios WHERE nombre = :usuario AND passw = :clave`,
      [usuario, clave]
    );

    await connection.close();

    if (result.rows.length > 0) {
      res.send("Login exitoso. Bienvenido " + usuario);
    } else {
      res.status(401).send("Usuario o contraseña incorrectos");
    }

  } catch (err) {
    console.error(err);
    res.status(500).send("Error en el servidor");
  }
});

app.listen(3000, () => {
  console.log("Servidor corriendo en http://localhost:3000");
});

10
Errores Frecuentes y Soluciones
Cannot find module '../routes/login'
CausaSe ejecutó node server.js desde la carpeta raíz. Fixcd js → node server.js
ORA-12541: no listener
CausaOracle no está corriendo. FixIniciar el servicio OracleServiceXE desde Servicios de Windows.
ORA-01017: invalid username/password
CausaEl usuario o contraseña en db.js no coinciden con Oracle. FixVerificar user y password en js\db.js.
ORA-00942: la tabla o vista no existe
CausaLa tabla usuarios no fue creada en el esquema del usuario. FixEjecutar el CREATE TABLE del paso 5 en SQL Developer.
EADDRINUSE: address already in use :::3000
CausaEl puerto 3000 ya lo usa otro proceso (servidor anterior). FixCerrar la terminal anterior o cambiar el puerto en server.js.
ERR_CONNECTION_REFUSED (página no carga)
CausaEl servidor Node no está corriendo. FixIr a la carpeta js\ y ejecutar node server.js.
